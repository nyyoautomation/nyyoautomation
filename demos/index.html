Included with every build

  • A free install kit matched to your stack, with the build
  • WordPress plugin, Shopify app embed, or Wix / Webflow / HTML script
  • Ready links for Telegram / Slack / Discord when the bot lives there
  • Importable n8n / Make workflows (JSON) when automation is the deliverable
  • Google Sheets copy + Apps Script packs when Sheets is the hub
  • Connectors for Sheets / Airtable / webhooks, so your tools stay in charge

The install kit is free and included: you only pay for the build. Items not built yet for a given stack are on request (free).
