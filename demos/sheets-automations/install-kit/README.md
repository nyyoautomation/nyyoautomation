# Google Sheets — free install kit

**Install kit: free, included with every package.**

## Option A — Apps Script file
1. Open your Google Sheet
2. Extensions → Apps Script
3. Paste `Code.gs` → Save
4. Reload the sheet → menu **Nyyo**

## Option B — Make a copy (template)
We publish a template Sheet at handover and you use **File → Make a copy**.
Public template link: **on request (free)** (created under your Drive or a shared demo Sheet).

No add-on fee.
