## How I work

1. **Scope**: you send the task; I reply with what I'll deliver and when.
2. **Deliver**: files plus a short report explaining method and sources.
3. **Verify**: every claim is linked to a source (explorer, page, dataset), so you can check it.
4. **Handover**: code and data are yours, with usage notes.
